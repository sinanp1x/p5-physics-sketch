# p5-physics-sketch

A p5.js + Matter.js physics sketch — a generic physics demonstration built with matter.js, p5.js, p5.play.js, and p5.sound.js. No game-specific assets, just a physics sandbox.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js
